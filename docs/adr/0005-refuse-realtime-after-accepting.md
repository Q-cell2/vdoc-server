# ADR 0005：已结束或不存在的会话，先接受连接再用关闭码拒绝

状态：已采纳（2026-10-16）

## 背景

浏览器拿不到 WebSocket 握手失败的 HTTP 状态码；Node 22 自带的 WebSocket 在握手被拒时只触发 `error`、不触发 `close`，导致 `@vrealtime/client` 的 `connect()` 一直等待。

## 决定

路由格式不对的请求在握手阶段直接 404。格式正确但会话不可用时，先接受升级，再用关闭码断开：`4000 + HTTP 状态码`，例如 4404（不存在）、4410（已结束）。

## 结果

- 客户端能明确知道原因，例如"会话已结束，请重新申请"。
- 对无效会话也会完成一次握手，开销很小；会话 id 是 128 位随机数，无法枚举。
